GitOps Agent

This add-on is not configured yet. Point it at a git repository and it will keep your Home Assistant configuration in sync.

  1. 1
    Open this add-on's Configuration tab and set repo_url to the git URL of your Home Assistant config repository.
  2. 2
    Optionally set branch (defaults to main) and git_username / git_token for a private repository.
  3. 3
    Save the configuration and restart the add-on.

The agent starts in dry run mode: once configured it only reports differences here until dry run is turned off.
